# ⚠️ Important Notice

This feature has been disabled for GitHub Pages due to how it handles file paths and routing.

It will not function correctly when hosted on GitHub Pages because the required files cannot be reliably resolved in that environment.

It also will not work when opened directly from local files (using `file://`), since browser security rules and path handling prevent proper loading of required scripts.

## 🗃️ Note
